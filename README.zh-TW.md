# mc-161807 (Pre-Classic)
開發階段：2009-05-16（至 18:07 UTC+2）

## 非官方名稱
雖然已知存在此版本，但它在啟動器中缺失，且未在其他地方被存檔，因此目前被視為遺失的版本。  
版本名稱來自 Notch 的 IRC 訊息：
https://archive.org/download/Minecraft_IRC_Logs_2009/history/files/May-15-to-June-03-2009/2009-05-16.075419-0400EDT.txt.~1~

``(12:07:06) notch: minecraft alpha is available. I need someone on windows, someone on mac and someone on linux!``

Minecraft Wiki 使用 `mc-161607` 作為該版本的標識（因為使用的是 UTC 時間格式）。
而 `mc-161807` 表示的是 UTC+2（瑞典時區）。

## 變更
- 將 com.mojang.rubydung 重新命名為 com.mojang.minecraft
- 新增用於運行遊戲的 Applet

## 準確性
該版本僅已發送給 [dock](https://minecraft.gamepedia.com/Hayden_Scott-Baron) 和 [fartron](https://forums.tigsource.com/index.php?action=profile;u=61) 進行測試。  
目前沒有現存的備份。  
我們可以假定此次更新中已為首次發布完成了所有必要的更改。
