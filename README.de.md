# mc-161807 (Pre-Classic)
Entwicklungsphase: 16. Mai 2009 (bis 18:07 UTC+2)

## Inoffizieller Name
Obwohl bekannt ist, dass diese Version existiert, fehlt sie im Launcher und wurde nirgendwo anders archiviert; daher gilt sie derzeit als verloren.  
Der Versionsname stammt aus Notchs IRC-Nachricht:  
https://archive.org/download/Minecraft_IRC_Logs_2009/history/files/May-15-to-June-03-2009/2009-05-16.075419-0400EDT.txt.~1~

``(12:07:06) notch: minecraft alpha is available. I need someone on windows, someone on mac and someone on linux!``

Das Minecraft Wiki verwendet `mc-161607` für diese Version, da es das UTC-Zeitformat nutzt.  
`mc-161807` würde UTC+2 entsprechen (Zeitzone Schweden).

## Änderungen
- Umbenennung von com.mojang.rubydung zu com.mojang.minecraft
- Applet zum Starten des Spiels hinzugefügt

## Genauigkeit
Diese Version wurde nur zum Testen an [dock](https://minecraft.gamepedia.com/Hayden_Scott-Baron) und [fartron](https://forums.tigsource.com/index.php?action=profile;u=61) gesendet.  
Es gibt keine vorhandene Sicherungskopie.  
Wir können davon ausgehen, dass in diesem Update alle notwendigen Änderungen für die Erstveröffentlichung vorgenommen wurden.
