# mc-161807 (Pre-Classic)
Utvecklingsfas: 16 maj 2009 (till 18:07 UTC+2)

## Oofficiellt namn
Även om denna version är känd att existera saknas den i startprogrammet och har inte arkiverats någon annanstans, vilket innebär att den för närvarande anses vara förlorad.  
Versionsnamnet är taget från Notchs IRC-meddelande:  
https://archive.org/download/Minecraft_IRC_Logs_2009/history/files/May-15-to-June-03-2009/2009-05-16.075419-0400EDT.txt.~1~

``(12:07:06) notch: minecraft alpha is available. I need someone on windows, someone on mac and someone on linux!``

Minecraft Wiki använder `mc-161607` för denna version eftersom de använder UTC-format.  
`mc-161807` skulle vara i UTC+2 (Sveriges tidszon).

## Ändringar
- Bytt namn com.mojang.rubydung till com.mojang.minecraft
- Lagt till Applet för att köra spelet

## Noggrannhet
Denna version har endast skickats till [dock](https://minecraft.gamepedia.com/Hayden_Scott-Baron) och [fartron](https://forums.tigsource.com/index.php?action=profile;u=61) för testning.  
Det finns ingen befintlig säkerhetskopia.  
Vi kan anta att alla nödvändiga ändringar för den första utgåvan har gjorts i denna uppdatering.
