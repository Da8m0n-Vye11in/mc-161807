# mc-161807 (Pre-Classic)
Phase de développement : 16 mai 2009 (jusqu'à 18:07 UTC+2)

## Nom non officiel
Bien que l'existence de cette version soit connue, elle est absente du lanceur et n'a pas été archivée ailleurs, ce qui signifie qu'elle est actuellement perdue.  
Le nom de la version est tiré du message IRC de Notch :  
https://archive.org/download/Minecraft_IRC_Logs_2009/history/files/May-15-to-June-03-2009/2009-05-16.075419-0400EDT.txt.~1~

``(12:07:06) notch: minecraft alpha is available. I need someone on windows, someone on mac and someone on linux!``

Minecraft Wiki utilise `mc-161607` pour cette version car il utilise le format UTC.  
`mc-161807` correspondrait à UTC+2 (fuseau horaire de la Suède).

## Changements
- Renommé com.mojang.rubydung en com.mojang.minecraft
- Ajout d'un Applet pour exécuter le jeu
