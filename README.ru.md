# mc-161807 (Pre-Classic)
Стадия разработки: 16 мая 2009 г. (до 18:07 UTC+2)

## Неофициальное название
Хотя известно о существовании этой версии, она отсутствует в лаунчере и не была заархивирована в других местах, поэтому в настоящее время считается утерянной.  
Название версии взято из IRC-сообщения Notch:  
https://archive.org/download/Minecraft_IRC_Logs_2009/history/files/May-15-to-June-03-2009/2009-05-16.075419-0400EDT.txt.~1~

``(12:07:06) notch: minecraft alpha is available. I need someone on windows, someone on mac and someone on linux!``

Minecraft Wiki использует обозначение `mc-161607` для этой версии (так как используется формат времени UTC).  
`mc-161807` соответствует UTC+2 (часовой пояс Швеции).

## Изменения
- Переименование com.mojang.rubydung в com.mojang.minecraft
- Добавлено Applet для запуска игры

## Точность
Эта версия была отправлена только [dock](https://minecraft.gamepedia.com/Hayden_Scott-Baron) и [fartron](https://forums.tigsource.com/index.php?action=profile;u=61) для тестирования.  
Резервных копий не существует.  
Можно предположить, что в этом обновлении были внесены все необходимые изменения для первого релиза.
