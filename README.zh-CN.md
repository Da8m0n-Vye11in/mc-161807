# mc-161807 (Pre-Classic)
开发阶段：2009-05-16（至 18:07 UTC+2）

## 非官方名称
虽然已知存在此版本，但它在启动器中缺失，且未在其他地方被存档，因此目前被视为丢失的版本。  
版本名称来自 Notch 的 IRC 消息：
https://archive.org/download/Minecraft_IRC_Logs_2009/history/files/May-15-to-June-03-2009/2009-05-16.075419-0400EDT.txt.~1~

``(12:07:06) notch: minecraft alpha is available. I need someone on windows, someone on mac and someone on linux!``

Minecraft Wiki 使用 `mc-161607` 标识该版本（因为他们使用的是 UTC 时间格式）。
而 `mc-161807` 表示的是 UTC+2（瑞典时区）。

## 变更
- 将 com.mojang.rubydung 重命名为 com.mojang.minecraft
- 添加了用于运行游戏的 Applet

## 准确性
该版本仅发送给 [dock](https://minecraft.gamepedia.com/Hayden_Scott-Baron) 和 [fartron](https://forums.tigsource.com/index.php?action=profile;u=61) 进行测试。  
没有现存的备份。  
我们可以假定此次更新中已经为首次发布完成了所有必要的更改。
