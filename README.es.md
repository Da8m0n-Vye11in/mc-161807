# mc-161807 (Pre-Classic)
Fase de desarrollo: 16 de mayo de 2009 (hasta las 18:07 UTC+2)

## Nombre no oficial
Aunque se sabe que existe esta versión, falta en el lanzador y no ha sido archivada en otros lugares, por lo que actualmente se considera perdida.  
El nombre de la versión se toma del mensaje de IRC de Notch:  
https://archive.org/download/Minecraft_IRC_Logs_2009/history/files/May-15-to-June-03-2009/2009-05-16.075419-0400EDT.txt.~1~

``(12:07:06) notch: minecraft alpha is available. I need someone on windows, someone on mac and someone on linux!``

Minecraft Wiki usa `mc-161607` para esta versión porque emplea el formato de hora UTC.  
`mc-161807` correspondería a UTC+2 (zona horaria de Suecia).

## Cambios
- Renombrado com.mojang.rubydung a com.mojang.minecraft
- Añadido Applet para ejecutar el juego

## Precisión
Esta versión solo ha sido enviada a [dock](https://minecraft.gamepedia.com/Hayden_Scott-Baron) y [fartron](https://forums.tigsource.com/index.php?action=profile;u=61) para pruebas.  
No existe copia de seguridad.  
Podemos asumir que todos los cambios necesarios para la primera versión se realizaron en esta actualización.
